# Radiator Store — Full-Stack E-Commerce Learning Project

An SEO-focused full-stack online store for heating radiators (steel panel, aluminum sectional, and bimetallic radiators), built step by step in strict mentor-mentee mode.

## Goals

- Build a production-style e-commerce store tailored to real heating-equipment domain requirements (heat output calculation, connection types, section sizing, accessories).
- Prioritize technical SEO from day one (Angular SSR, semantic HTML, clean slugs, structured data, Core Web Vitals).
- Learn modern TypeScript, Angular, Node.js, backend architecture, cloud deployment, and AI/LLM engineering best practices.

## Planned Tech Stack

- **Frontend:** Angular (standalone components, Signals, Reactive Forms, Angular SSR)
- **Backend (Stage 1):** Node.js, TypeScript, Express (modular monolith)
- **Backend (Stage 2):** NestJS, microservices on Google Cloud (Cloud Run)
- **Quality & Tooling:** TypeScript strict mode, ESLint, Prettier, GitHub Actions CI, SonarQube / SonarCloud
